## 📌 Descripción del Proyecto

Este repositorio contiene un proyecto integral de análisis de datos enfocado en la evaluación y visualización de los **indicadores de salud mental y bienestar** a nivel global. El objetivo principal es identificar patrones, correlaciones y tendencias significativas que afectan a diferentes demografías y regiones, transformando datos brutos en insights accionables para entender mejor los factores que influyen en el bienestar emocional y psicológico.

A través de la manipulación, limpieza y exploración de datos, este estudio busca visibilizar problemáticas críticas y ofrecer una base analítica sólida que pueda servir de apoyo para la toma de decisiones informadas o futuras investigaciones en el área de la salud pública.

🚀 Etapas del Análisis
Recopilación y Limpieza de Datos (EDA): Tratamiento de valores nulos, eliminación de duplicados, normalización de variables y preparación del dataset para el análisis.

Análisis Exploratorio: Identificación de variables clave, distribución de indicadores de salud mental por rangos de edad, género y localización geográfica.

Visualización de Datos: Creación de gráficos interactivos y estáticos para representar de manera clara los hallazgos y facilitar la comprensión de las métricas de bienestar.

Conclusiones e Insights: Resumen de los factores socioeconómicos o demográficos que presentan mayor correlación con los niveles de estrés, ansiedad o satisfacción general.

⚙️ Instrucciones de Instalación y Uso
Para replicar este análisis localmente, sigue estos pasos:

1. Clonar el repositorio:
git clone [https://github.com/lucianayelicich/analisis_salud_mental.git](https://github.com/lucianayelicich/analisis_salud_mental.git)
cd analisis_salud_mental

2. Crear y activar un entorno virtual (recomendado):
python -m venv env
   # En Windows:
   .\env\Scripts\activate
   # En macOS/Linux:
   source env/bin/activate

3. Instalar las dependencias:
pip install -r requirements.txt

4. Ejecutar los notebooks:
Abre tu entorno de Jupyter o VS Code y explora los archivos dentro de la carpeta notebooks/.
